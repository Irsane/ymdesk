# Hailu — десктоп-клиент Яндекс Музыки

Полноценное приложение для ПК на **Electron + React** с супер-чёрным дизайном и
анимациями. Подключается к API Яндекс Музыки и позволяет слушать музыку как в
официальном клиенте.

## Возможности

- 🔐 **Авторизация по OAuth-токену** (хранится локально, проверяется при входе)
- 🌊 **Моя волна** — персональное радио с выбором характера/настроения/языка и
  бесконечной догрузкой треков
- 🏠 **Главная** — персональные подборки из ленты
- 🔍 **Поиск** треков с живым (debounce) результатом
- ❤️ **Мне нравится** — понравившиеся треки, лайк/дизлайк прямо из списка
- 📂 **Плейлисты** пользователя и сгенерированные подборки
- 🎧 **Плеер на HTML5 Audio**: play/pause, перемотка, громкость, следующий/предыдущий,
  перемешивание и **3 режима повтора** (выкл / очередь / одна песня), горячая клавиша Space

## Архитектура

```
electron/
  main.js      — main-процесс: окно (без системного меню), IPC, запросы к API
  preload.js   — безопасный мост (contextBridge) renderer ↔ main
  yandex.js    — клиент API Яндекс Музыки + Моя волна (rotor) + подпись mp3 (md5)
src/
  App.jsx      — роутинг разделов, проверка авторизации
  player.jsx   — контекст плеера (HTML5 Audio, очередь, волна, повтор)
  api.js       — обёртка над preload-мостом
  components/  — Logo, Login, Sidebar, PlayerBar, TrackList, MyWave
  views/       — Home, Search, Liked, Playlist
  styles.css   — супер-чёрная тема с анимациями
```

Все сетевые запросы выполняются в **main-процессе** Electron: OAuth-токен
никогда не попадает в окно, и нет проблем с CORS.

## Запуск (разработка)

```bash
npm install
npm run dev        # Vite (5173) + Electron с hot-reload
```

## Сборка дистрибутива

```bash
npm run dist       # собирает renderer и упаковывает приложение через electron-builder
```

Готовый Windows `.exe` также автоматически собирается в GitHub Actions и
публикуется в Releases.

## Как получить OAuth-токен

На экране входа есть кнопка «Получить OAuth-токен». Она открывает страницу
Яндекс OAuth; после входа скопируйте значение `access_token` из адресной строки
и вставьте в приложение.

## Дисклеймер

Приложение использует неофициальный API Яндекс Музыки и предназначено для
личного использования. Для воспроизведения требуется активная подписка.
