# YM Desk — десктоп-клиент Яндекс Музыки

Полноценное приложение для ПК на **Electron + React**, которое подключается к
API Яндекс Музыки и позволяет слушать музыку как в официальном клиенте.

## Возможности

- 🔐 **Авторизация по OAuth-токену** (токен хранится локально, проверяется при входе)
- 🏠 **Главная** — персональные подборки из ленты
- 🔍 **Поиск** треков с живым (debounce) результатом
- ❤️ **Мне нравится** — понравившиеся треки, лайк/дизлайк прямо из списка
- 📂 **Плейлисты** пользователя и сгенерированные подборки
- 🎧 **Плеер на HTML5 Audio**: play/pause, перемотка, громкость, следующий/предыдущий,
  повтор, перемешивание, горячая клавиша Space

## Архитектура

```
electron/
  main.js      — main-процесс: окно, IPC, запросы к API (токен и подпись не утекают, нет CORS)
  preload.js   — безопасный мост (contextBridge) renderer ↔ main
  yandex.js    — клиент API Яндекс Музыки + подпись ссылок на mp3 (md5)
src/
  App.jsx      — роутинг разделов, проверка авторизации
  player.jsx   — контекст плеера (HTML5 Audio, очередь)
  api.js       — обёртка над preload-мостом
  components/  — Login, Sidebar, PlayerBar, TrackList
  views/       — Home, Search, Liked, Playlist
  styles.css   — тёмная тема
```

Все сетевые запросы выполняются в **main-процессе** Electron: OAuth-токен
никогда не попадает в окружение страницы, и нет проблем с CORS.

## Запуск (разработка)

```bash
npm install
npm run dev        # Vite (5173) + Electron с hot-reload
```

## Сборка дистрибутива

```bash
npm run dist       # собирает renderer и упаковывает приложение через electron-builder
```

## Как получить OAuth-токен

На экране входа есть кнопка «Получить OAuth-токен». Она открывает страницу
Яндекс OAuth; после входа скопируйте значение `access_token` из адресной строки
(после `#access_token=...`) и вставьте в приложение.

## Дисклеймер

Приложение использует неофициальный API Яндекс Музыки и предназначено для
личного использования. Требуется активная подписка для воспроизведения.
