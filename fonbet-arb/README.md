# FONBET Arb — поиск вилок в линии FONBET

Десктоп-приложение на **Python + PySide6**, которое скачивает линию букмекерской
конторы **FONBET** и показывает **вилки** (арбитражные ситуации).

> **Вилка** — это когда по противоположным исходам одного события сумма обратных
> коэффициентов меньше единицы:
>
> ```
> 1/коэф₁ + 1/коэф₂ + …  <  1
> ```
>
> Тогда, распределив ставку пропорционально, вы получаете прибыль при любом
> исходе. Приложение считает это автоматически и показывает, сколько процентов
> банка ставить на каждый исход.

## Что умеет

- 🔎 Тянет линию FONBET и ищет вилки по рынкам:
  - Исход **1X2** (с ничьёй) и **Победитель** без ничьи (теннис, баскетбол);
  - **Тотал Б/М** на совпадающую линию;
  - **Фора 1/2** на зеркальную линию (+X ↔ −X);
  - **Двойной шанс**, **Обе забьют Да/Нет**.
- 📊 Таблица: спорт, событие, рынок, какие ставки делать (исход × коэффициент и
  доля банка), гарантированная прибыль в %.
- 🚀 Кнопка **«Перейти»** — открывает страницу события на сайте FONBET.
- 🔁 Автообновление по таймеру + фильтр по минимальной прибыли.
- 🧪 **Демо-режим** — проверка работы без подключения к FONBET.

## Запуск из исходников

```bash
pip install -r requirements.txt

python run.py            # обычный режим (линия с сайта FONBET)
python run.py --demo     # офлайн на демо-данных (вкладка «Демо-режим» в окне)
python run.py --scan --demo   # консоль: вывести найденные вилки без окна
```

## Сборка .exe для Windows и SmartScreen

Полная инструкция — в [`BUILD.md`](BUILD.md). Коротко:

```bash
pip install pyinstaller
pyinstaller --noconfirm --windowed --name FonbetArb ^
  --add-data "fonbet_arb/sample_line.json;fonbet_arb" run.py
```

⚠️ **Про SmartScreen честно.** Предупреждение SmartScreen вызывает не сам факт
«.exe», а **отсутствие подписи кода** и низкая «репутация» файла. Полностью убрать
его можно **только сертификатом подписи кода** (обычный или EV). Без сертификата:

- запускайте **portable**-сборку **локально** (не качая из интернета) — тогда
  с файла не ставится «метка интернета» (Zone.Identifier) и SmartScreen обычно
  молчит;
- если файл всё же скачан — у скачанного `.exe` можно снять метку:
  `Свойства → Разблокировать`, либо PowerShell `Unblock-File FonbetArb.exe`;
- запуск **из исходников** (`python run.py`) SmartScreen не трогает вовсе.

Никто не может «гарантированно убрать SmartScreen» у неподписанного .exe — это
свойство Windows, а не приложения.

## Как это работает внутри

```
fonbet_arb/
  client.py        — загрузка линии FONBET (events/list) + парсинг в события
  markets.py       — маппинг факторов FONBET и группы противоположных исходов
  arb.py           — математика вилок: sum(1/коэф) < 1, расчёт долей банка
  gui.py           — окно PySide6: таблица, кнопки, автообновление
  sample_line.json — демо-снимок линии для офлайн-проверки
run.py             — точка входа (окно / --scan / --demo)
```

У FONBET **нет официального публичного API**. Используется тот же JSON-эндпоинт
линии, что и сайт конторы (`/events/list`). Хосты у FONBET «плавают», поэтому
клиент перебирает несколько кандидатов. Идентификаторы факторов (типов исходов)
вынесены в `markets.py` — если контора сменит формат, маппинг правится там же
(или через внешний `factors.json`).

## Важно

- Приложение **только показывает** расхождения коэффициентов и не размещает
  ставки. Коэффициенты у букмекера меняются ежесекундно — реальная вилка может
  «закрыться» до того, как вы успеете поставить.
- Используйте на свой риск и в соответствии с правилами FONBET и
  законодательством вашей страны.
